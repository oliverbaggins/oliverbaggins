## 📌 Projetos em destaque

### [StoryCraft — Gerador de Histórias de Usuário com IA](https://github.com/oliverbaggins/pi-storycraft-server)

Aplicação desenvolvida com Node.js, Express e MongoDB, integrada à API da OpenAI para auxiliar na geração e organização de histórias de usuário a partir de informações estruturadas.

**Tecnologias:** JavaScript, Node.js, Express, MongoDB e OpenAI API.

### [Integração da IA Generativa no Desenvolvimento Web](https://github.com/oliverbaggins/framework-conceitual-artigo)

Pesquisa acadêmica sobre a utilização de ferramentas de IA generativa no desenvolvimento web, considerando percepções profissionais, benefícios, limitações e desafios. O trabalho propõe um framework conceitual para orientar a integração dessas ferramentas ao ciclo de desenvolvimento.

**Reconhecimento:** artigo aceito para publicação na Revista Eletrônica Argentina-Brasil de TIC.

### [Framework de Saúde e Riscos em Projetos Open Source](https://github.com/oliverbaggins/framework-saude-projetos-open-source-artigo)

Pesquisa e desenvolvimento de uma abordagem para coleta e análise de métricas de repositórios GitHub, utilizando indicadores para investigar aspectos relacionados à atividade, manutenção e comunidade de projetos de código aberto.

**Reconhecimento:** 1º lugar em Mérito Científico — Exatas e Engenharias, UniFAP 2025.

**Tecnologias:** Python, Pandas e visualização de dados.

### [Previsão do Valor do Tesouro Selic](https://github.com/oliverbaggins/previsao-valor-selic)

Projeto de análise de dados e experimentação com modelos de machine learning para previsão de valores do Tesouro Selic, incluindo comparação de desempenho entre diferentes algoritmos.

**Tecnologias:** Python, Pandas, NumPy e Scikit-learn.
